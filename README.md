# ALFA Sports — Demo Platform Starter

## Run locally
1. Extract the ZIP.
2. Open `public/index.html` in a modern browser.
3. Choose English, አማርኛ or Afaan Oromo from the language selector.
4. Explore Sports, Live, Virtual, My Account and Admin.
5. Select sample outcomes and place a demo selection. The browser stores demo-only activity locally.

No installation or server is required for this static prototype.

## Included
- Responsive desktop/mobile web prototype.
- Three-language interface foundation.
- Sample football fixtures and illustrative odds.
- Demo selection slip and local demo-credit ledger.
- Admin prototype dashboard, local reset and JSON export.
- PostgreSQL conceptual schema in `database/schema.sql`.
- Scale/security/architecture blueprint in `docs/ARCHITECTURE.md`.

## Important limitations
This is not a licensed betting service and is not production-ready. It contains no real-money betting, payment integration, deposits, withdrawals, live sports data, settlement engine, casino/virtual-game provider, secure authentication, or server-side database connection. Demo credits have no cash value. Do not deploy this prototype to accept money or real wagers.

Before any regulated launch, obtain jurisdiction-specific legal advice and all required licences/approvals. Complete age and identity verification, AML, responsible-use, privacy, payment safeguarding, independent security, game/RNG certification (where applicable), provider contracts and regulator reporting. Have qualified engineers conduct threat modelling, code review, load testing and penetration testing.
